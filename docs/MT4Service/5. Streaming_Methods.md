# MT4Service — Streaming Methods (Mid-Level API)

> The same server streams as [`MT4Account`](../MT4Account/5.%20Streaming_Methods/Streaming_Methods.Overview.md), but mapped to typed objects — a friendly `Tick`, typed trade events, a live account snapshot with margin. Each returns a `{ unsubscribe() }` handle.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over `MT4Account`'s raw streams.

**Implementation:** `src/MT4Service.ts`. **Demos:** `examples/demos/service/05_service_streaming.js`.

[← MT4Service Overview](./MT4Service.Overview.md) · [low-level group ↓](../MT4Account/5.%20Streaming_Methods/Streaming_Methods.Overview.md)

---

## 🎯 Why these methods exist

On `MT4Account`, each stream delivers the raw `*Data` and you read it with `getXxx()`. `MT4Service` maps each payload to a plain object — `subscribeQuotes` gives you a `Tick`, `subscribeTrades` typed event lists, `subscribeOpenedOrdersProfit` a live account snapshot (**including margin**, which `AccountSummary` lacks on MT4).

```ts
const sub = service.subscribeQuotes(['EURUSD'], (tick) => {
  console.log(tick.symbol, tick.bid, tick.ask);   // ✅ plain fields
}, (err) => console.log(err.message));
// later: sub.unsubscribe();
```

---

## 📋 Methods

| Method | Callback receives | Notes |
|--------|-------------------|-------|
| **`subscribeQuotes(symbols, cb, onError?)`** | `Tick` | Live ticks for the given symbols. |
| **`subscribeTrades(cb, onError?)`** | `{ type, newOrders, updatedOrders, removedOrders, newHistoryOrders, account }` | Fills / modifications / closes. |
| **`subscribeOpenedOrdersProfit(intervalMs, cb, onError?)`** | `{ orders, account }` | Periodic open-orders-with-profit + account (**margin**). |
| **`subscribeOpenedOrdersTickets(intervalMs, cb, onError?)`** | `{ positionTickets, pendingTickets, serverTime }` | Periodic ticket snapshot. |
| **`subscribeConnectState(cb, onError?)`** | the connection-state object | Terminal connection health. |

Each returns a **`Subscription`** = `{ unsubscribe(): void }`.

---

## 📦 `Tick` (DTO)

Delivered by `subscribeQuotes`:

| Field | Type | Description |
| ----- | ---- | ----------- |
| `symbol` | `string` | Symbol. |
| `bid` / `ask` / `last` | `number` | Prices. |
| `volume` | `number` | Tick volume. |
| `time` | `number` | Tick time, **milliseconds** (server). |
| `timeUtc` | `number` | The same in real UTC (ms), when the server reports it. |

The `account` object in the trade / profit streams carries `{ balance, credit, equity, margin, freeMargin, profit, marginLevel, login }`.

## 📖 Method details

### 1) `subscribeQuotes(symbols, cb, onError?)`

```ts
const sub = service.subscribeQuotes(['EURUSD', 'GBPUSD'], (t) => {
  console.log(`${t.symbol} bid ${t.bid} ask ${t.ask} @ ${new Date(t.timeUtc).toISOString().slice(11, 23)}`);
}, (e) => console.log('tick error:', e.message || e));

setTimeout(() => sub.unsubscribe(), 5000);
```

### 2) `subscribeTrades(cb, onError?)`

```ts
const sub = service.subscribeTrades((ev) => {
  for (const o of ev.newOrders)     console.log('OPEN  #', o.ticket, o.symbol);
  for (const o of ev.removedOrders) console.log('CLOSE #', o.ticket, 'P/L', o.profit.toFixed(2));
  if (ev.account) console.log('equity', ev.account.equity.toFixed(2));
}, (e) => console.log('trade error:', e.message || e));
```

### 3) `subscribeOpenedOrdersProfit(intervalMs, cb, onError?)` — **live margin**

```ts
// One snapshot is enough to read margin on MT4
const sub = service.subscribeOpenedOrdersProfit(1000, (ev) => {
  if (ev.account) console.log(`equity ${ev.account.equity.toFixed(2)} margin ${ev.account.margin.toFixed(2)} free ${ev.account.freeMargin.toFixed(2)}`);
  sub.unsubscribe();
}, (e) => console.log(e.message));
```

### 4) `subscribeOpenedOrdersTickets(intervalMs, cb, onError?)`

```ts
const sub = service.subscribeOpenedOrdersTickets(1000, (ev) => {
  console.log('positions:', ev.positionTickets, 'pending:', ev.pendingTickets);
}, (e) => console.log(e.message));
```

### 5) `subscribeConnectState(cb, onError?)`

```ts
const sub = service.subscribeConnectState((state) => {
  console.log('connected:', state.isConnected, 'alive:', state.isAlive);
}, (e) => console.log(e.message));
```

---

## 🧩 Notes & Tips

- **Select symbols first** — `subscribeQuotes` only streams symbols in Market Watch.
- **Live margin lives here** — read `subscribeOpenedOrdersProfit`'s `account` (or `MT4Sugar.getMargin()`), not `AccountInfo`.
- **Re-subscribe on `onError`** (transport failure / unexpected end); `unsubscribe()` is a clean cancel, not an error.
- **Always unsubscribe** when done.
