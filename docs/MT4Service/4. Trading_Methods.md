# MT4Service — Trading Methods (Mid-Level API)

> Send, modify and close orders with plain argument objects — the facade builds the protobuf request, fills the market price from a quote, and routes through the exactly-once `tradeCall`.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over [`MT4Account`](../MT4Account/4.%20Trading_Operations/Trading_Operations.Overview.md).

**Implementation:** `src/MT4Service.ts`. **Demos:** `examples/demos/service/04_service_demo.js`.

[← MT4Service Overview](./MT4Service.Overview.md) · [low-level group ↓](../MT4Account/4.%20Trading_Operations/Trading_Operations.Overview.md)

---

## 🎯 Why these methods exist

On `MT4Account` you build an `OrderSendRequest`, look up the current price, set each field, and read the reply with `getXxx()`. `MT4Service` takes one `OrderRequest` object, **fills the market price from `quote()` when you omit it**, maps the result to a typed `OrderResult`, and still guarantees the trade is **sent exactly once**.

```ts
const res = await service.orderSend({ symbol: 'EURUSD', cmd: 'BUY', lots: 0.01 });  // price auto-filled
console.log('ticket', res.ticket, 'at', res.price);
```

---

## ⚠️ Exactly-once & unknown outcomes

Every trade routes through the SDK's `tradeCall` — **sent once, never re-sent**:

- **Broker refusal** → `MrpcError` with `mqlIntCode` (130 invalid stops, 131 invalid volume, 132 market closed, 134 no money, 138 requote). `err.operation` names the call.
- **Unknown outcome** (transport failure after the request may have landed, or MT4 128 timeout) → **`TradeOutcomeUnknownError`**. Reconcile with `openedOrders()` before retrying. See [Return Codes](../All_Guides/RETURN_CODES_REFERENCE.md).

## 📋 Methods

| Method | Returns | Notes |
|--------|---------|-------|
| **`orderSend(req)`** | `Promise<OrderResult>` | Market or pending order; market price auto-filled from `quote()`. |
| **`orderModify(req)`** | `Promise<{ modified: boolean }>` | Change SL/TP (and pending price/expiration). |
| **`orderClose(req)`** | `Promise<OrderCloseResult>` | Close a market order (full/partial) or delete a pending one; price/volume looked up when omitted. |
| **`orderCloseBy(ticket, oppositeTicket)`** | `Promise<{ closePrice, profit, closeTime }>` | Close an order by an opposite one. |

---

## 📦 DTOs

**`OrderRequest`** (input to `orderSend`):

| Field | Type | Description |
| ----- | ---- | ----------- |
| `symbol` | `string` | Symbol (required). |
| `cmd` / `action` | `'BUY'\|'SELL'\|'BUY_LIMIT'\|'SELL_LIMIT'\|'BUY_STOP'\|'SELL_STOP'` or number | Order command (required). |
| `lots` / `volume` | `number` | Volume (required). |
| `price` | `number` | Omit for market orders → filled from `quote()` (ask for buys, bid for sells). |
| `slippage` | `number` | Points. |
| `stopLoss` / `takeProfit` | `number` | SL / TP prices. |
| `comment` | `string` | Comment. |
| `magicNumber` / `magic` | `number` | EA magic. |
| `expiration` | `Date \| number` | Pending expiry. |

**`OrderResult`** = `{ ticket, errorCode, price, lots, volume, comment, openTime }`.
**`OrderModifyRequest`** = `{ ticket, stopLoss?, takeProfit?, price?, expiration? }`.
**`OrderCloseRequest`** = `{ ticket, volume?/lots?, price?, slippage?, symbol?, type? }`.
**`OrderCloseResult`** = `{ mode, historyComment }` (`mode`: 0 market closed · 1 pending deleted).

## 📖 Method details

### 1) `orderSend(req): Promise<OrderResult>`

```ts
// Market BUY — price filled from the current ask
const res = await service.orderSend({ symbol: 'EURUSD', cmd: 'BUY', lots: 0.01, slippage: 30, comment: 'NodeMT4' });

// Pending BUY LIMIT with SL/TP
await service.orderSend({ symbol: 'EURUSD', cmd: 'BUY_LIMIT', lots: 0.01, price: 1.0500, stopLoss: 1.0450, takeProfit: 1.0600 });
```

### 2) `orderModify(req): Promise<{ modified }>`

Pass the full new SL/TP.

```ts
const r = await service.orderModify({ ticket: 123456, stopLoss: 1.0950, takeProfit: 1.1100 });
console.log('modified:', r.modified);
```

### 3) `orderClose(req): Promise<OrderCloseResult>`

Omit `price`/`volume`/`symbol`/`type` and the facade looks them up (one `openedOrders()` + `quote()` round-trip).

```ts
// Close the whole order
await service.orderClose({ ticket: 123456 });
// Partial close
await service.orderClose({ ticket: 123456, volume: 0.05 });
```

### 4) `orderCloseBy(ticket, oppositeTicket)`

```ts
const r = await service.orderCloseBy(123456, 123457);   // same symbol, opposite direction
console.log(`closed by @ ${r.closePrice}  profit ${r.profit.toFixed(2)}`);
```

### Error handling

```ts
import { TradeOutcomeUnknownError, MrpcError } from '@metarpc/nodemt4';
try {
  await service.orderSend({ symbol: 'EURUSD', cmd: 'BUY', lots: 0.01 });
} catch (e) {
  if (e instanceof TradeOutcomeUnknownError) { /* reconcile with openedOrders() — do NOT resend */ }
  else if (e instanceof MrpcError) console.log('refused:', e.code, e.mqlIntCode);
}
```

---

## 🧩 Notes & Tips

- **Market price is optional** — omit `price` for BUY/SELL and the facade fills it from `quote()`.
- **Slippage is in points.**
- **Never blind-retry a trade** — on `TradeOutcomeUnknownError`, check `openedOrders()` first.
- **Errors are exceptions** — `await` inside `try/catch`.
