# MT4Service — Orders & History Methods (Mid-Level API)

> Read open orders, pending orders and closed-order history as typed `OrderInfo` objects — the protobuf unwrapping and type filtering are done for you.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over [`MT4Account`](../MT4Account/2.%20Orders_History/Orders_History.Overview.md).

**Implementation:** `src/MT4Service.ts`. **Demos:** `examples/demos/service/04_service_demo.js`.

[← MT4Service Overview](./MT4Service.Overview.md) · [low-level group ↓](../MT4Account/2.%20Orders_History/Orders_History.Overview.md)

---

## 🎯 Why these methods exist

On `MT4Account`, `openedOrders()` returns a protobuf `*Data` whose list you iterate with `getOrderInfosList()` and read each order with `getXxx()`. `MT4Service` maps every order to a plain **`OrderInfo`** and adds the common filters (positions vs pending) you'd otherwise write yourself.

```ts
// Mid-level
const positions = await service.positions();           // open market orders → OrderInfo[]
const pending   = await service.pendingOrders();        // pending orders → OrderInfo[]
const { totalCount, orders } = await service.ordersHistory(from, to);
```

> **MT4 is order-centric.** There are no positions in the MT5 sense — a "position" here is just an open **market order** (type `0` BUY / `1` SELL). Pending orders are types `2–5`.

---

## 📋 Methods

| Method | Returns | Notes |
|--------|---------|-------|
| **`openedOrders(sortType?)`** | `Promise<OrderInfo[]>` | All open market + pending orders. |
| **`positions(magic?)`** | `Promise<OrderInfo[]>` | Open market orders (types 0/1), optionally filtered by magic. |
| **`pendingOrders(magic?)`** | `Promise<OrderInfo[]>` | Pending orders (types 2–5), optionally filtered by magic. |
| **`openedOrdersTickets()`** | `Promise<number[]>` | Just the ticket numbers. |
| **`ordersHistory(from, to, opts?)`** | `Promise<OrdersHistory>` | Closed orders in a window (plain `Date`s). |

`opts` for `ordersHistory`: `{ sort?: number; page?: number; perPage?: number }` (sort defaults to close-time-desc).

---

## 📦 `OrderInfo` & `OrdersHistory` (DTOs)

**`OrderInfo`**

| Field | Type | Description |
| ----- | ---- | ----------- |
| `ticket` | `number` | Order ticket. |
| `symbol` | `string` | Symbol. |
| `type` | `number` | `0` BUY · `1` SELL · `2` BUY_LIMIT · `3` SELL_LIMIT · `4` BUY_STOP · `5` SELL_STOP. |
| `lots` | `number` | Volume. |
| `openPrice` | `number` | Entry price. |
| `openTime` | `number` | Open time, seconds (server). |
| `stopLoss` / `takeProfit` | `number` | SL / TP (0 = none). |
| `profit` | `number` | Floating P/L (open) or realized (history). |
| `swap` / `commission` | `number` | Swap / commission. |
| `comment` | `string` | Comment. |
| `magic` | `number` | Magic number. |
| `expiration` | `number` | Pending expiry, seconds. |
| `accountLogin` | `number` | Owning account. |
| `closeTime?` / `closePrice?` | `number` | Set for **closed** (history) orders. |

**`OrdersHistory`** = `{ totalCount: number; orders: OrderInfo[] }`.

## 📖 Method details

### 1) `openedOrders(sortType?): Promise<OrderInfo[]>`

```ts
for (const o of await service.openedOrders()) {
  console.log(`#${o.ticket} ${o.symbol} type ${o.type} lots ${o.lots} P/L ${o.profit.toFixed(2)}`);
}
```

### 2) `positions(magic?)` / `pendingOrders(magic?)`

```ts
const market  = await service.positions();        // types 0/1
const pending = await service.pendingOrders();     // types 2-5
const eaOnly  = await service.positions(12345);    // only magic 12345
console.log(`${market.length} open, ${pending.length} pending`);
```

### 3) `openedOrdersTickets(): Promise<number[]>`

```ts
const tickets = await service.openedOrdersTickets();
console.log('open tickets:', tickets);
```

### 4) `ordersHistory(from, to, opts?): Promise<OrdersHistory>`

Pass plain `Date`s (UTC) — the facade converts to the broker's server-time window.

```ts
const { totalCount, orders } = await service.ordersHistory(
  new Date(Date.now() - 7 * 864e5),   // from
  new Date(),                          // to
  { perPage: 100, page: 0 },
);
console.log(`${totalCount} closed`);
const net = orders.reduce((s, o) => s + o.profit + o.swap + o.commission, 0);
console.log('net P/L:', net.toFixed(2));
```

---

## 🧩 Notes & Tips

- **Floating P/L** of open orders: `(await service.positions()).reduce((s, o) => s + o.profit, 0)` — or `MT4Sugar.getTotalProfit()`.
- **History window** is passed as `Date`s; internally it becomes a server-time range.
- **Errors are exceptions** — `await` inside `try/catch`.
