# MT4Service — Account Methods (Mid-Level API)

> Connect, then read account state and performance as plain typed objects — no protobuf, no `getXxx()` chains.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over [`MT4Account`](../MT4Account/1.%20Account_Information/Account_Information.Overview.md) that returns plain JS types and typed objects.

**Implementation:** `src/MT4Service.ts`, wrapping the low-level `accountSummary` and `TradeStats` calls on `MT4Account`.

**Demos:** `examples/demos/service/04_service_demo.js` · `examples/demos/run_all.js`.

[← MT4Service Overview](./MT4Service.Overview.md) · [low-level group ↓](../MT4Account/1.%20Account_Information/Account_Information.Overview.md)

## 🎯 Why these methods exist

**Problem** — on `MT4Account`, `accountSummary()` returns a protobuf `*Data` you must unwrap, and the stats calls need you to build a `TradeStatsRequest` and set a UTC timestamp yourself:

```ts
// Low-level (MT4Account)
import { TradeStatsPb, toTimestamp } from '@metarpc/nodemt4';
const req = new TradeStatsPb.TradeStatsRequest();
req.setFromUtc(new Date(Date.now() - 30 * 864e5).toISOString());
const s = await account.tradeStats(req);
console.log(s.getProfitFactor());   // .getXxx() everywhere
```

**Solution** — `MT4Service` builds the requests and maps the replies to typed objects:

```ts
// Mid-level (MT4Service)
const a = await service.getAccountInfo();                 // AccountInfo
const stats = await service.getTradeStats(new Date(Date.now() - 30 * 864e5)); // TradeStats
console.log(a.balance, stats.profitFactor);               // ✅ plain fields
```

**Advantages**

- ✅ One call → the whole account as a typed `AccountInfo`.
- ✅ Plain JS types — no `.getXxx()`, no enum imports.
- ✅ `tradeMode` decoded to `'DEMO' | 'CONTEST' | 'REAL'`.
- ✅ The stats methods take a plain `Date` and handle the UTC request for you.

## 🔌 Connection lifecycle

| Method | Returns | Purpose |
|--------|---------|---------|
| **`connect(login, password, server)`** *(or a `ConnectOptions`)* | `Promise<boolean>` | Start / re-attach a terminal (ConnectEx by broker server name). |
| **`getId(user?, password?)`** | `Promise<string>` | The terminal session id (defaults to the last connect's). |
| **`reconnect()`** | `Promise<boolean>` | Re-run the last connect (same id/name). |
| **`checkConnect()`** | `Promise<boolean>` | Liveness probe — `true` when the terminal answers. |
| **`isConnected()`** | `boolean` | Sync flag after a successful connect. |
| **`disconnect(deleteTerminal?)`** | `Promise<void>` | Stop the terminal (`true` also deletes it) and close the channel. |
| **`close()`** | `void` | Close the channel without touching the terminal. |

```ts
import { MT4Service } from '@metarpc/nodemt4';

const service = MT4Service.create('mt4.mrpc.pro', 443);   // apiKey from MRPC_API_KEY, else TRIAL
await service.connect(500000, 'password', 'TeleTrade-Demo');
// … use it …
await service.disconnect(true);   // free the trial terminal slot
```

## 📋 Account methods

| Method | Returns | Low-level equivalent |
|--------|---------|----------------------|
| **`getAccountInfo()`** | `Promise<AccountInfo>` | `accountSummary()`, mapped |
| **`getTradeStats(from)`** | `Promise<TradeStats>` | `tradeStats(req)` |
| **`getTradeStatsEquityHistory(from, excludeSameBars?)`** | `Promise<{ stats, equity }>` | `tradeStatsEquityHistory(req)` |

| **`getTradeUnrealizedPl(from)`** | `Promise<any[]>` | `tradeUnrealizedPl(req)` |

## 📦 `AccountInfo` (DTO)

Returned by `getAccountInfo()`:

| Field | Type | Description |
| ----- | ---- | ----------- |
| `login` | `number` | Account number. |
| `currency` | `string` | Deposit currency. |
| `balance` | `number` | Balance (without floating P/L). |
| `equity` | `number` | Equity (balance + floating P/L). |
| `credit` | `number` | Credit. |
| `leverage` | `number` | Leverage (100 = 1:100). |
| `name` | `string` | Account holder. |
| `company` | `string` | Broker name. |
| `server` | `string` | Trade server (e.g. `TeleTrade-Demo`). |
| `tradeMode` | `'DEMO' \| 'CONTEST' \| 'REAL' \| 'UNKNOWN'` | Decoded account type. |
| `tradeModeCode` | `number` | Raw trade-mode enum value. |
| `isInvestor` | `boolean` | Connected with the investor (read-only) password. |
| `serverTime` | `number` | Broker server time — **seconds** since epoch. |
| `utcServerShiftMinutes` | `number` | `serverTime = utc + shift·60` — use it to build server-time windows. |

> ⚠️ **No margin here.** MT4's `AccountSummary` carries no reliable margin — `AccountInfo` omits it. For live margin / free margin / margin level use **`MT4Sugar.getMargin()`** (or the [`subscribeOpenedOrdersProfit`](./5.%20Streaming_Methods.md) stream), which read an `OnOpenedOrdersProfit` snapshot. Floating profit = `equity − balance`.

## 📈 `TradeStats` & `EquityPoint` (DTOs)

`getTradeStats(from)` → **`TradeStats`**: `trades`, `profitability`, `profitFactor`, `expectancy`, `ghpr`, `growthPercent`, `sharpeRatio`, `zScore`, `standardDeviation`, `pips`, `lots`, `deposits`, `withdrawals`, `commissions`, `bestTrade`, `worstTrade`, `bestTradePips`, `worstTradePips`, `averageWin`, `averageLost`, `averageTradeLength`, `longsWon`, `shortsWon`, `maxBalanceDrawdownRaw/Relative`, `maxEquityDrawdownRaw/Relative`, `markets`.

`getEquityHistory(from)` → **`EquityPoint[]`**: each `{ time, timeUtc, balance, equity, realizedPl, unrealizedPl, cashFlow, balanceDrawdownRaw/Relative, equityDrawdownRaw/Relative }`.

## 📖 Method details

### 1) `getAccountInfo(): Promise<AccountInfo>`

The whole account in one call.

```ts
const a = await service.getAccountInfo();
console.log(`${a.name} #${a.login} on ${a.server}`);
console.log(`balance ${a.balance.toFixed(2)} ${a.currency}  equity ${a.equity.toFixed(2)}  1:${a.leverage}  ${a.tradeMode}`);
console.log('floating P/L:', (a.equity - a.balance).toFixed(2));
```

### 2) `getTradeStats(from: Date | number): Promise<TradeStats>`

Aggregated statistics since `from` (UTC).

```ts
const s = await service.getTradeStats(new Date(Date.now() - 30 * 864e5));   // last 30 days
console.log(`trades ${s.trades}  PF ${s.profitFactor.toFixed(2)}  growth ${s.growthPercent.toFixed(1)}%`);
console.log(`best ${s.bestTrade.toFixed(2)}  worst ${s.worstTrade.toFixed(2)}  maxDD ${s.maxEquityDrawdownRelative.toFixed(1)}%`);
```

### 3) `getEquityHistory(from, excludeSameBars = false): Promise<EquityPoint[]>`

The equity-curve points for a chart.

```ts
const curve = await service.getEquityHistory(new Date(Date.now() - 7 * 864e5), true);
const series = curve.map((p) => [p.timeUtc, p.equity]);   // ready for a chart
console.log('points:', curve.length);
```

### 4) `getTradeStatsEquityHistory(from, excludeSameBars = false): Promise<{ stats, equity }>`

Stats **and** the curve in one call.

```ts
const { stats, equity } = await service.getTradeStatsEquityHistory(new Date(Date.now() - 90 * 864e5));
console.log(`PF ${stats.profitFactor.toFixed(2)} over ${stats.trades} trades, ${equity.length} curve points`);
```

### 5) `getTradeUnrealizedPl(from: Date | number): Promise<any[]>`

Best/worst unrealized P/L per open order since `from` (run-up / drawdown).

```ts
for (const e of await service.getTradeUnrealizedPl(new Date(Date.now() - 864e5))) {
  console.log(`#${e.ticket} ${e.symbol}  best +${e.maxUnrealizedPl?.toFixed?.(2)}  worst ${e.minUnrealizedPl?.toFixed?.(2)}`);
}
```

## 🧩 Notes & Tips

- **Errors are exceptions** — a server error rejects with `MrpcError`; `await` inside `try/catch`.
- **Time windows are UTC** for the stats methods (they build the UTC request for you). Account/history *windows* elsewhere use server time.
- **Session is automatic** — `connect()` captures the terminal id; later calls attach it for you.
