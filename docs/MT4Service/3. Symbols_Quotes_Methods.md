# MT4Service — Symbols & Quotes Methods (Mid-Level API)

> Prices, contract specs, OHLC bars and the server timezone — as typed `Quote` / `SymbolParams` / `Bar` objects, with the request-building done for you.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over [`MT4Account`](../MT4Account/3.%20Symbols_Quotes/Symbols_Quotes.Overview.md).

**Implementation:** `src/MT4Service.ts`. **Demos:** `examples/demos/service/04_service_demo.js`.

[← MT4Service Overview](./MT4Service.Overview.md) · [low-level group ↓](../MT4Account/3.%20Symbols_Quotes/Symbols_Quotes.Overview.md)

---

## 🎯 Why these methods exist

On `MT4Account` you build a `QuoteRequest` / `SymbolParamsManyRequest` / `QuoteHistoryRequest` and read the reply with `getXxx()`. `MT4Service` takes plain strings and returns typed objects — and adds the conveniences the flat client had: `ensureSymbol` (select + wait for a quote) and `lastBars` (the newest N bars without computing a server-time window).

```ts
const q  = await service.quote('EURUSD');            // Quote { bid, ask, time }
const sp = await service.symbolParams('EURUSD');     // SymbolParams { digits, point, volumeMin, … }
const bars = await service.lastBars('EURUSD', 'H1', 100);  // Bar[]
```

## 📋 Methods

| Method | Returns | Notes |
|--------|---------|-------|
| **`symbolList()`** | `Promise<{name,index}[]>` | Every symbol the broker exposes. |
| **`symbolSelect(symbol, select?)`** | `Promise<boolean>` | Add/remove in Market Watch. |
| **`quote(symbol)`** | `Promise<Quote>` | Latest bid/ask of one symbol. |
| **`quoteMany(symbols)`** | `Promise<Quote[]>` | Latest ticks of several symbols. |
| **`symbolParams(symbol)`** | `Promise<SymbolParams>` | Contract spec of one symbol. |
| **`symbolParamsAll()`** | `Promise<SymbolParams[]>` | Contract spec of all symbols. |
| **`tickValueWithSize(symbols)`** | `Promise<{symbol,tickValue,tickSize,contractSize}[]>` | Sizing inputs. |
| **`getServerTimezone()`** | `Promise<ServerTimezone>` | Broker UTC offset. |
| **`ensureSymbol(symbol, waitMs?)`** | `Promise<Quote>` | Select, then wait for a two-sided quote. |
| **`quoteHistory(symbol, timeframe, from, to)`** | `Promise<Bar[]>` | OHLC bars for a window (plain `Date`s). |
| **`lastBars(symbol, timeframe, count, shiftMin?)`** | `Promise<Bar[]>` | The newest `count` bars (window auto-widened). |

> **Timeframe:** `'M1' \| 'M5' \| 'M15' \| 'M30' \| 'H1' \| 'H4' \| 'D1' \| 'W1' \| 'MN1'` or the `TIMEFRAMES` ordinal.

---

## 📦 DTOs

**`Quote`** = `{ symbol, bid, ask, high, low, time }` (time = seconds, server).
**`SymbolParams`** = `{ name, description, digits, point, spreadFloat, contractSize, volumeMin, volumeMax, volumeStep, volumeLimit, stopsLevel, freezeLevel, tickValue, tickSize, swapLong, swapShort, swapMode, currencyBase, currencyProfit, currencyMargin, tradeMode, tradeExeMode, tradeCalcMode, marginInitial, marginMaintenance, isSelected, visible, bid, time, path }` (the `bid` field is a **stale** snapshot — price from `quote()`).
**`Bar`** = `{ time, open, high, low, close, tickVolume, realVolume, spread }` (time = seconds, server; sorted ascending).
**`ServerTimezone`** = `{ server, source, utcOffsetSeconds, utcOffsetMinutes, validatedUtc }`.

## 📖 Method details

### 1) `quote(symbol)` / `quoteMany(symbols)`

```ts
const q = await service.quote('EURUSD');
console.log(`bid ${q.bid} ask ${q.ask} spread ${(q.ask - q.bid).toFixed(5)}`);

const many = await service.quoteMany(['EURUSD', 'GBPUSD', 'USDJPY']);
for (const m of many) console.log(m.symbol, m.bid, m.ask);
```

### 2) `symbolParams(symbol)` / `symbolParamsAll()`

```ts
const sp = await service.symbolParams('EURUSD');
const pip = sp.point * (sp.digits === 3 || sp.digits === 5 ? 10 : 1);
console.log(`digits ${sp.digits}  pip ${pip}  minLot ${sp.volumeMin}  step ${sp.volumeStep}`);
```

### 3) `ensureSymbol(symbol, waitMs = 10000)`

Select a symbol and wait until it reports a real two-sided quote (fresh symbols show `0` for a moment).

```ts
const q = await service.ensureSymbol('BTCUSD');
console.log('ready:', q.bid, q.ask);
```

### 4) `quoteHistory(symbol, tf, from, to)` / `lastBars(symbol, tf, count, shiftMin?)`

```ts
// Newest 100 H1 bars — no server-time math needed
const info = await service.getAccountInfo();
const bars = await service.lastBars('EURUSD', 'H1', 100, info.utcServerShiftMinutes);
console.log('bars:', bars.length, 'last close', bars.at(-1)?.close);

// Or an explicit window (plain Dates)
const range = await service.quoteHistory('EURUSD', 'H1', new Date(Date.now() - 864e5), new Date());
```

### 5) `getServerTimezone(): Promise<ServerTimezone>`

```ts
const tz = await service.getServerTimezone();
console.log(`${tz.server}  UTC offset ${(tz.utcOffsetMinutes / 60).toFixed(1)} h`);
```

### 6) `tickValueWithSize(symbols)`

```ts
for (const i of await service.tickValueWithSize(['EURUSD', 'XAUUSD'])) {
  console.log(`${i.symbol}  tickValue ${i.tickValue}  tickSize ${i.tickSize}  contract ${i.contractSize}`);
}
```

---

## 🧩 Notes & Tips

- **Select before you stream/quote** — a fresh symbol reports `bid=ask=0`; `ensureSymbol` handles the wait.
- **`SymbolParams.bid` is stale** — always price from `quote()` / the tick stream.
- **`lastBars` is the easy path** for "the newest N bars"; `quoteHistory` is for an explicit range.
- **Errors are exceptions** — `await` inside `try/catch`.
