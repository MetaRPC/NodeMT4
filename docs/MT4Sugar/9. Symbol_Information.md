# MT4Sugar — Symbol Information (High-Level API)

> Quick symbol facts — the full spec, availability, decimals and the minimum stop level.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/10_sugar_advanced.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`getSymbolInfo(symbol)`** | `Promise<SymbolParams>` | Full contract spec. |
| **`getAllSymbols()`** | `Promise<string[]>` | Every symbol name. |
| **`isSymbolAvailable(symbol)`** | `Promise<boolean>` | Does the broker know it? |
| **`getMinStopLevel(symbol)`** | `Promise<number>` | Min SL/TP distance, in points. |
| **`getSymbolDigits(symbol)`** | `Promise<number>` | Price decimal places. |

`SymbolParams` is the full spec (digits, point, lot limits, swaps, margin, …) — see [MT4Service · Symbols & Quotes](../MT4Service/3.%20Symbols_Quotes_Methods.md).

---

## 📖 Method details

```ts
const info = await sugar.getSymbolInfo('EURUSD');
console.log(`digits ${info.digits}  point ${info.point}  minLot ${info.volumeMin}  step ${info.volumeStep}`);
console.log('minStopLevel', await sugar.getMinStopLevel('EURUSD'), 'pts');
console.log('available:', await sugar.isSymbolAvailable('BTCUSD'));
```

---

## 💡 Usage examples

### 1) Pip size from the spec

```ts
const info = await sugar.getSymbolInfo('EURUSD');
const pip = info.point * (info.digits === 3 || info.digits === 5 ? 10 : 1);
console.log('pip size:', pip);
```

### 2) Guard a trade on availability

```ts
if (!(await sugar.isSymbolAvailable('XAUUSD'))) {
  console.log('symbol not available on this account');
}
```

---

## 🔧 Notes

- **`getMinStopLevel` / `getSymbolDigits`** read from `getSymbolInfo` (MT4 has no per-property symbol RPC).
- **Sizing** uses the spec's `tickValue` / `tickSize` — see [Risk Management](./10.%20Risk_Management.md).
