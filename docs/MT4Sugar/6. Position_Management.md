# MT4Sugar — Position Management (High-Level API)

> Close and modify open orders by ticket — fully, partially, by symbol, or all at once.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/07_sugar_trading.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

> On MT4 a "position" is an open **market order** (one ticket per fill). These helpers operate by ticket.

---

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`closePosition(ticket)`** | `Promise<boolean>` | Close an order fully (deletes a pending). |
| **`closePositionPartial(ticket, volume)`** | `Promise<boolean>` | Close part of an order. |
| **`closeAllPositions()`** | `Promise<number>` | Close every open position; returns the count. |
| **`closeAllBySymbol(symbol)`** | `Promise<number>` | Close every open position on a symbol. |
| **`modifyPositionSL(ticket, sl)`** | `Promise<boolean>` | Set SL (keeps TP). |
| **`modifyPositionTP(ticket, tp)`** | `Promise<boolean>` | Set TP (keeps SL). |
| **`modifyPositionSLTP(ticket, sl, tp)`** | `Promise<boolean>` | Set both SL and TP. |

Close helpers throw `MrpcError` on a broker rejection. The price and volume are looked up for you.

---

## 📖 Method details

```ts
await sugar.closePosition(123456);              // full close
await sugar.closePositionPartial(123456, 0.05); // partial
console.log('closed', await sugar.closeAllBySymbol('EURUSD'), 'EURUSD orders');

await sugar.modifyPositionSL(123456, 1.0950);   // keeps the existing TP
await sugar.modifyPositionSLTP(123456, 1.0950, 1.1100);
```

> `modifyPositionSL` / `modifyPositionTP` read the order first and re-send the unchanged side, so you never accidentally clear it.

---

## 💡 Usage examples

### 1) Flatten everything (panic close)

```ts
const n = await sugar.closeAllPositions();
console.log(`closed ${n} positions`);
```

### 2) Move stop to break-even

```ts
const pos = await sugar.getPositionByTicket(123456);
if (pos) await sugar.modifyPositionSL(pos.ticket, pos.openPrice);
```

## 🔧 Notes

- **Trailing a stop?** See the [Trailing Stop orchestrator](../Orchestrators/11_Trailing_stop.md) (`modifyPositionSL` in a loop).
- **Unknown outcome** on a close throws `TradeOutcomeUnknownError` — reconcile before retrying.
