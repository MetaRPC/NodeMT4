# MT4Sugar — Trading with SL/TP (High-Level API)

> One-line orders that carry an absolute **stop-loss** and **take-profit**.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/07_sugar_trading.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Order |
|--------|---------|-------|
| **`buyMarketWithSLTP(symbol, volume, sl, tp)`** | `Promise<number>` | Market BUY + SL/TP. |
| **`sellMarketWithSLTP(symbol, volume, sl, tp)`** | `Promise<number>` | Market SELL + SL/TP. |
| **`buyLimitWithSLTP(symbol, volume, price, sl, tp)`** | `Promise<number>` | BUY LIMIT + SL/TP. |
| **`sellLimitWithSLTP(symbol, volume, price, sl, tp)`** | `Promise<number>` | SELL LIMIT + SL/TP. |

`sl` / `tp` are **absolute prices**. For pip-distance SL/TP see [Trading Helpers](./11.%20Trading_Helpers.md).

---

## 📖 Method details

```ts
// Market BUY with a 50-pip stop and 100-pip target (absolute prices)
const bid = await sugar.getBid('EURUSD');
const ticket = await sugar.buyMarketWithSLTP('EURUSD', 0.01, bid - 0.0050, bid + 0.0100);

// Pending BUY LIMIT with SL/TP
await sugar.buyLimitWithSLTP('EURUSD', 0.01, 1.0500, 1.0450, 1.0600);
```

---

## 💡 Usage examples

### 1) Derive SL/TP from pips, then open

```ts
const { sl, tp } = await sugar.calculateSLTP('EURUSD', 'BUY', 0, /*SL*/ 20, /*TP*/ 40);
await sugar.buyMarketWithSLTP('EURUSD', 0.01, sl, tp);
```

### 2) Respect the broker's minimum stop distance

```ts
const minPts = await sugar.getMinStopLevel('EURUSD');   // points
// ensure SL/TP are at least minPts away from price, else the broker refuses (mqlIntCode 130)
```

## 🔧 Notes

- **Absolute prices** here — pip-based helpers live in [Trading Helpers](./11.%20Trading_Helpers.md).
- **Stops level** — SL/TP too close to price are refused (`mqlIntCode` 130); check `getMinStopLevel()`.
