# MT4Sugar — Position Information (High-Level API)

> Read open positions (open market orders) — count, total P/L, per-symbol filters, lookup by ticket.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/08_sugar_positions.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`getOpenPositions()`** | `Promise<OrderInfo[]>` | All open market orders. |
| **`getPositionByTicket(ticket)`** | `Promise<OrderInfo \| undefined>` | One position by ticket. |
| **`getPositionsBySymbol(symbol)`** | `Promise<OrderInfo[]>` | Positions on one symbol. |
| **`hasOpenPosition(symbol)`** | `Promise<boolean>` | Any position on a symbol? |
| **`countOpenPositions()`** | `Promise<number>` | How many are open. |
| **`getTotalProfit()`** | `Promise<number>` | Summed floating P/L. |
| **`getProfitBySymbol(symbol)`** | `Promise<number>` | Summed floating P/L on a symbol. |

`OrderInfo` fields used here: `ticket`, `symbol`, `type` (0 BUY / 1 SELL), `lots`, `openPrice`, `profit`.

---

## 📖 Method details

```ts
const positions = await sugar.getOpenPositions();
console.log(`${await sugar.countOpenPositions()} open, floating ${(await sugar.getTotalProfit()).toFixed(2)}`);
for (const p of positions) {
  console.log(`#${p.ticket} ${p.symbol} ${p.type === 0 ? 'BUY' : 'SELL'} ${p.lots} @ ${p.openPrice} P/L ${p.profit.toFixed(2)}`);
}
```

---

## 💡 Usage examples

### 1) Per-symbol exposure

```ts
if (await sugar.hasOpenPosition('EURUSD')) {
  console.log('EURUSD P/L:', (await sugar.getProfitBySymbol('EURUSD')).toFixed(2));
}
```

### 2) Close the most-losing position

```ts
const worst = (await sugar.getOpenPositions()).sort((a, b) => a.profit - b.profit)[0];
if (worst && worst.profit < -50) await sugar.closePosition(worst.ticket);
```

---

## 🔧 Notes

- **Pending orders** aren't included here — use `service().pendingOrders()`.
- **Live P/L** reflects the last read; for continuous updates subscribe via `service().subscribeOpenedOrdersProfit`.
