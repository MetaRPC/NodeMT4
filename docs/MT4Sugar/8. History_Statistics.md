# MT4Sugar — History & Statistics (High-Level API)

> Closed-order history over ready-made windows, profit by window, and today's win/loss summary.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/09_sugar_history.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Window |
|--------|---------|--------|
| **`getDealsToday()`** | `Promise<OrderInfo[]>` | Closed today. |
| **`getDealsYesterday()`** | `Promise<OrderInfo[]>` | Closed yesterday. |
| **`getDealsThisWeek()`** | `Promise<OrderInfo[]>` | Since Monday. |
| **`getDealsThisMonth()`** | `Promise<OrderInfo[]>` | Since the 1st. |
| **`getDealsDateRange(from, to)`** | `Promise<OrderInfo[]>` | Custom window. |
| **`getProfitToday()` / `getProfitThisWeek()` / `getProfitThisMonth()`** | `Promise<number>` | Net profit of the window. |
| **`getDailyStats()`** | `Promise<DailyStats>` | Today's win/loss summary. |

**`DailyStats`** = `{ totalDeals, winningDeals, losingDeals, winRate, totalProfit, bestDeal, worstDeal }`.

---

## 📖 Method details

```ts
console.log('today', (await sugar.getDealsToday()).length, 'orders');
console.log('profit today', (await sugar.getProfitToday()).toFixed(2));

const s = await sugar.getDailyStats();
console.log(`deals ${s.totalDeals}  win ${s.winningDeals}/${s.totalDeals} (${s.winRate.toFixed(1)}%)  net ${s.totalProfit.toFixed(2)}`);
console.log(`best ${s.bestDeal.toFixed(2)}  worst ${s.worstDeal.toFixed(2)}`);
```

## 💡 Usage examples

### 1) Weekly P/L breakdown

```ts
console.log('this week:', (await sugar.getProfitThisWeek()).toFixed(2));
console.log('this month:', (await sugar.getProfitThisMonth()).toFixed(2));
```

### 2) Custom range

```ts
const from = new Date('2026-01-01'), to = new Date('2026-03-31');
const q1 = await sugar.getDealsDateRange(from, to);
console.log(`Q1 closed orders: ${q1.length}, net ${q1.reduce((s, d) => s + d.profit, 0).toFixed(2)}`);
```

---

## 🔧 Notes

- **Windows are local-day based** and converted to the broker's server-time window under the hood.
- **Deeper analytics** (profit factor, Sharpe, equity curve) live in the mid layer: `service().getTradeStats(from)` / `getEquityHistory(from)`.
