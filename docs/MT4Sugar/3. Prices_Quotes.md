# MT4Sugar — Prices & Quotes (High-Level API)

> One-liners for live prices — bid, ask, spread, a one-shot snapshot, and a price-wait helper.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`getBid(symbol)`** | `Promise<number>` | Latest bid. |
| **`getAsk(symbol)`** | `Promise<number>` | Latest ask. |
| **`getSpread(symbol)`** | `Promise<number>` | `ask − bid` (price units). |
| **`getPriceInfo(symbol)`** | `Promise<PriceInfo>` | bid / ask / spread-in-pips / time in one snapshot. |
| **`waitForPrice(symbol, targetBid, timeoutMs?)`** | `Promise<PriceInfo \| null>` | Poll until the bid reaches a target. |

**`PriceInfo`** = `{ symbol, bid, ask, spreadPips, time }` (time = seconds, server).

---

## 📖 Method details

```ts
const bid = await sugar.getBid('EURUSD');
const ask = await sugar.getAsk('EURUSD');
console.log('spread', (await sugar.getSpread('EURUSD')).toFixed(5));

const p = await sugar.getPriceInfo('EURUSD');
console.log(`bid ${p.bid} ask ${p.ask} spread ${p.spreadPips.toFixed(1)} pips`);
```

### `waitForPrice(symbol, targetBid, timeoutMs = 10000)`

Polls until the bid reaches `targetBid` (or returns the next tick when `targetBid` is `0`). Returns the last price, or `null` on timeout.

```ts
const hit = await sugar.waitForPrice('EURUSD', 1.1000, 15000);
console.log(hit ? `reached ${hit.bid}` : 'timed out');
```

---

## 💡 Usage examples

### 1) A simple price alert

```ts
const p = await sugar.waitForPrice('EURUSD', 1.1050, 30000);
if (p) console.log('🔔 EURUSD hit', p.bid);
```

### 2) Spread gate before trading

```ts
if ((await sugar.getSpread('EURUSD')) > 0.0003) {
  console.log('spread too wide — skipping');
}
```

---

## 🔧 Notes

- **Select first** — a fresh symbol reports `0`; use `service().ensureSymbol(sym)` or trade a symbol that's already in Market Watch.
- **For a continuous feed**, prefer the stream (`service().subscribeQuotes`) over polling `getBid` in a loop.
