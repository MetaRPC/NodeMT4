# MT4Sugar — Account Information (High-Level API)

> The full account snapshot and today's trading summary — the two highest-level account reads.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js` · `09_sugar_history.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`getAccountInfo()`** | `Promise<AccountInfo>` | Full account snapshot. |
| **`getDailyStats()`** | `Promise<DailyStats>` | Today's win/loss summary. |

**`AccountInfo`** = `{ login, currency, balance, equity, credit, leverage, name, company, server, tradeMode, tradeModeCode, isInvestor, serverTime, utcServerShiftMinutes }` (no margin — see [Balance & Margin](./2.%20Balance_Margin.md)).
**`DailyStats`** = `{ totalDeals, winningDeals, losingDeals, winRate, totalProfit, bestDeal, worstDeal }`.

---

## 📖 Method details

```ts
const a = await sugar.getAccountInfo();
console.log(`${a.name} #${a.login} on ${a.server}`);
console.log(`balance ${a.balance.toFixed(2)} ${a.currency}  equity ${a.equity.toFixed(2)}  1:${a.leverage}  ${a.tradeMode}`);

const s = await sugar.getDailyStats();
console.log(`today: ${s.totalDeals} deals, win ${s.winRate.toFixed(1)}%, net ${s.totalProfit.toFixed(2)}`);
```

---

## 💡 Usage examples

### 1) A one-line status banner

```ts
const a = await sugar.getAccountInfo();
console.log(`Acc ${a.login} | ${a.currency} | Bal ${a.balance.toFixed(2)} | Eq ${a.equity.toFixed(2)} | ${a.tradeMode}`);
```

### 2) End-of-day report

```ts
const s = await sugar.getDailyStats();
console.log(`📊 ${s.winningDeals}/${s.totalDeals} wins, net ${s.totalProfit.toFixed(2)} (best ${s.bestDeal.toFixed(2)}, worst ${s.worstDeal.toFixed(2)})`);
```

---

## 🔧 Notes

- **Margin fields** aren't in `AccountInfo` on MT4 — use [Balance & Margin](./2.%20Balance_Margin.md) (`getMargin`, live).
- **Deeper stats** (profit factor, equity curve) are in the mid layer: `service().getTradeStats(from)`.
