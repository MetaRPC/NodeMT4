# MT4Sugar — Simple Trading (High-Level API)

> One-line market and pending orders. Each returns the resulting **ticket**; a broker rejection throws `MrpcError`.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/07_sugar_trading.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Order |
|--------|---------|-------|
| **`buyMarket(symbol, volume)`** | `Promise<number>` | Market BUY. |
| **`sellMarket(symbol, volume)`** | `Promise<number>` | Market SELL. |
| **`buyLimit(symbol, volume, price)`** | `Promise<number>` | BUY LIMIT (below market). |
| **`sellLimit(symbol, volume, price)`** | `Promise<number>` | SELL LIMIT (above market). |
| **`buyStop(symbol, volume, price)`** | `Promise<number>` | BUY STOP (above market). |
| **`sellStop(symbol, volume, price)`** | `Promise<number>` | SELL STOP (below market). |

Each resolves with the **order ticket** (a number). The market price is filled automatically for `buyMarket` / `sellMarket`.

---

## ⚠️ Rejections & unknown outcomes

- A **broker refusal** throws `MrpcError` (`mqlIntCode`: 132 market closed, 134 no money, …).
- A trade whose transport outcome is unknown throws `TradeOutcomeUnknownError` — **never blindly resend**; reconcile with `getOpenPositions()`. See [Return Codes](../All_Guides/RETURN_CODES_REFERENCE.md).

---

## 📖 Method details

```ts
// Market
const t1 = await sugar.buyMarket('EURUSD', 0.01);
const t2 = await sugar.sellMarket('EURUSD', 0.01);

// Pending
const t3 = await sugar.buyLimit('EURUSD', 0.01, 1.0500);
const t4 = await sugar.sellStop('EURUSD', 0.01, 1.0400);
console.log('tickets', t1, t2, t3, t4);
```

## 💡 Usage examples

### 1) Open and immediately read it back

```ts
const ticket = await sugar.buyMarket('EURUSD', 0.01);
const pos = await sugar.getPositionByTicket(ticket);
console.log(`#${pos.ticket} ${pos.symbol} vol ${pos.lots} @ ${pos.openPrice}`);
```

### 2) Safe open with error handling

```ts
import { TradeOutcomeUnknownError } from '@metarpc/nodemt4';
try {
  const ticket = await sugar.buyMarket('EURUSD', 0.01);
} catch (e) {
  if (e instanceof TradeOutcomeUnknownError) console.log('outcome unknown — check positions');
  else console.log('rejected:', e.message);
}
```
