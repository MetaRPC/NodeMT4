# MT4Sugar — Balance & Margin (High-Level API)

> One-liners for account money — balance, equity, margin, free margin, floating profit.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Source |
|--------|---------|--------|
| **`getBalance()`** | `Promise<number>` | `AccountSummary` (cheap). |
| **`getEquity()`** | `Promise<number>` | `AccountSummary` (cheap). |
| **`getProfit()`** | `Promise<number>` | `equity − balance`. |
| **`getMargin()`** | `Promise<number>` | **live snapshot** (`OnOpenedOrdersProfit`). |
| **`getFreeMargin()`** | `Promise<number>` | **live snapshot**. |
| **`getMarginLevel()`** | `Promise<number>` | **live snapshot** (percent). |

> ⚠️ **Margin on MT4.** `AccountSummary` carries no reliable margin, so `getMargin` / `getFreeMargin` / `getMarginLevel` take one `OnOpenedOrdersProfit` snapshot (a ~1 s stream read). When the account is flat they fall back to `equity` (free) / `0`. `getBalance` / `getEquity` / `getProfit` are the cheap summary reads.

---

## 📖 Method details

```ts
console.log('balance', (await sugar.getBalance()).toFixed(2));
console.log('equity ', (await sugar.getEquity()).toFixed(2));
console.log('profit ', (await sugar.getProfit()).toFixed(2));   // floating
console.log('margin ', (await sugar.getMargin()).toFixed(2));   // live snapshot
console.log('free   ', (await sugar.getFreeMargin()).toFixed(2));
console.log('level  ', (await sugar.getMarginLevel()).toFixed(0) + '%');
```

## 💡 Usage examples

### 1) A margin-health check

```ts
const level = await sugar.getMarginLevel();   // 0 when flat
if (level > 0 && level < 100)      console.log('⚠️ margin level critical!');
else if (level > 0 && level < 200) console.log('⚠️ low margin level');
else                               console.log('✅ healthy');
```

### 2) Affordability before a trade

```ts
if ((await sugar.getFreeMargin()) < (await sugar.calculateRequiredMargin('EURUSD', 0.1))) {
  console.log('not enough free margin for 0.1 lots');
}
```

---

## 🔧 Notes

- **Minimise live reads** — if you need margin repeatedly, subscribe once via `service().subscribeOpenedOrdersProfit` and read from the callback instead of calling `getMargin()` in a loop.
- **Floating profit** is `getProfit()` (= equity − balance); per-order profit is in [Position Information](./7.%20Position_Information.md).
