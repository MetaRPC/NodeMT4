# MT4Sugar — Trading Helpers (High-Level API)

> Market orders with SL/TP given as **pip distances** from entry — the common case in one line.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/07_sugar_trading.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`buyMarketWithPips(symbol, volume, stopLossPips, takeProfitPips)`** | `Promise<number>` | Market BUY, SL/TP as pip distances. |
| **`sellMarketWithPips(symbol, volume, stopLossPips, takeProfitPips)`** | `Promise<number>` | Market SELL, SL/TP as pip distances. |

These compute the absolute SL/TP from the current price (via `calculateSLTP`) and open with [`buyMarketWithSLTP`](./5.%20Trading_SLTP.md) / `sellMarketWithSLTP`. Returns the ticket.

---

## 📖 Method details

```ts
// BUY 0.01 lots with a 20-pip stop and 40-pip target
const ticket = await sugar.buyMarketWithPips('EURUSD', 0.01, 20, 40);

// SELL with the same geometry
await sugar.sellMarketWithPips('EURUSD', 0.01, 20, 40);
```

---

## 💡 Usage examples

### 1) Risk-sized, pip-based entry

```ts
const lots = await sugar.calculatePositionSize('EURUSD', 1.0, 20);   // 1% over a 20-pip stop
const ticket = await sugar.buyMarketWithPips('EURUSD', lots, 20, 40);  // 1:2 R:R
```

---

## 🔧 Notes

- **Pip size** is derived from the symbol spec (`point × 10` on 3/5-digit symbols).
- **Minimum stop distance** still applies — a too-tight pip stop is refused (`mqlIntCode` 130); check `getMinStopLevel()`.
