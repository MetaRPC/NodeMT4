# MT4Sugar — Connection (High-Level API)

> One-liner connect and liveness checks — the fastest way onto the terminal.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners with smart defaults over [MT4Service](../MT4Service/MT4Service.Overview.md) / [MT4Account](../MT4Account/MT4Account.Master.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js`.

## 🧱 Build the stack & reach the layers below

```ts
import { MT4Sugar } from '@metarpc/nodemt4';

// create() builds Service → Account underneath in one call
const sugar = MT4Sugar.create('mt4.mrpc.pro', 443);

await sugar.quickConnect(500000, 'password', 'TeleTrade-Demo');
// … use it …
await sugar.service().disconnect(true);
```

* `MT4Sugar.create(host?, port?, apiKey?, id?)` → the whole stack (defaults `mt4.mrpc.pro:443`).
* `sugar.service()` → the `MT4Service` underneath · `sugar.account()` → the `MT4Account`.

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`quickConnect(login?, password?, server?)`** | `Promise<boolean>` | Connect; falls back to env vars. |
| **`isConnected()`** | `boolean` | `true` after a successful connect. |
| **`ping()`** | `Promise<boolean>` | Liveness probe — terminal answers. |

---

## 📖 Method details

### `quickConnect(login?, password?, server?)`

Connects by login / password / server. **Any omitted argument falls back to an env var** — `MT4_LOGIN`, `MT4_PASSWORD`, `MT4_SERVER` — so you can keep credentials out of code. Throws `MrpcError` if none of the three is available.

```ts
// explicit
await sugar.quickConnect(500000, 'password', 'TeleTrade-Demo');

// from env (MT4_LOGIN / MT4_PASSWORD / MT4_SERVER)
await sugar.quickConnect();
```

### `isConnected()`

Synchronous flag — no round-trip. `true` once `quickConnect` has succeeded.

### `ping()`

A lightweight health check (CheckConnect) against the terminal; returns `false` instead of throwing if the terminal is down — safe to call in a loop.

## 💡 Usage examples

### 1) Connect from environment

```ts
const sugar = MT4Sugar.create();
if (!(await sugar.quickConnect())) throw new Error('connect failed');
console.log('connected:', sugar.isConnected());
```

### 2) Reconnect guard before an action

```ts
if (!sugar.isConnected() || !(await sugar.ping())) {
  await sugar.quickConnect();
}
```

### 3) Clean shutdown (frees the trial terminal)

```ts
try {
  // … work …
} finally {
  await sugar.service().disconnect(true); // true = delete the terminal, free the slot
}
```

---

## 🔧 Notes

- **Env fallback** makes `quickConnect()` with no args the norm in scripts — set `MT4_LOGIN` / `MT4_PASSWORD` / `MT4_SERVER`.
- **`ping()` never throws** — it's a boolean probe.
- **Free the terminal** with `disconnect(true)` at the end of a one-shot run (a trial allows one terminal per IP).
