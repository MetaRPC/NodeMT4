# MT4Sugar — Risk Management (High-Level API)

> Size positions by risk, cap by free margin, estimate margin, derive SL/TP from pips, and pre-flight a trade.

**🧩 API Layer:** **HIGH-LEVEL** — over [MT4Service](../MT4Service/MT4Service.Overview.md).

**Implementation:** `src/MT4Sugar.ts`. **Demos:** `examples/demos/sugar/10_sugar_advanced.js`.

[← MT4Sugar API Overview](./MT4Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`calculatePositionSize(symbol, riskPercent, stopLossPips)`** | `Promise<number>` | Lots so the stop risks `riskPercent`% of balance. |
| **`getMaxLotSize(symbol)`** | `Promise<number>` | Largest lot the free margin (80%) allows. |
| **`calculateRequiredMargin(symbol, volume)`** | `Promise<number>` | Margin to open `volume` lots. |
| **`canOpenPosition(symbol, volume)`** | `Promise<{ ok, reason }>` | Pre-flight: availability, volume limits, free margin. |
| **`calculateSLTP(symbol, dir, entry, slPips, tpPips)`** | `Promise<{ sl, tp }>` | Absolute SL/TP from pip distances. |

All are **read-only / calculations** — nothing is traded.

---

## 📖 Method details

```ts
// Lot size for 1% risk over a 20-pip stop
const lots = await sugar.calculatePositionSize('EURUSD', 1.0, 20);

// Margin & cap
console.log('margin for 0.1 lots:', (await sugar.calculateRequiredMargin('EURUSD', 0.1)).toFixed(2));
console.log('max lot:', await sugar.getMaxLotSize('EURUSD'));

// SL/TP from pips (entry 0 = current ask/bid)
const { sl, tp } = await sugar.calculateSLTP('EURUSD', 'BUY', 0, 20, 40);

// Pre-flight
const can = await sugar.canOpenPosition('EURUSD', lots);
if (!can.ok) console.log('cannot open:', can.reason);
```

> **Margin estimate on MT4:** `calculateRequiredMargin` uses the symbol's initial margin when the broker reports it, else estimates from `contractSize × ask ÷ leverage`.

## 💡 Usage examples

### 1) Risk-sized entry, end to end

```ts
const lots = await sugar.calculatePositionSize('EURUSD', 1.0, 20);
const can = await sugar.canOpenPosition('EURUSD', lots);
if (can.ok) {
  const { sl, tp } = await sugar.calculateSLTP('EURUSD', 'BUY', 0, 20, 40);
  await sugar.buyMarketWithSLTP('EURUSD', lots, sl, tp);
}
```

---

## 🔧 Notes

- **Free margin** is read live (`getFreeMargin` → `OnOpenedOrdersProfit`); `getMaxLotSize` and `canOpenPosition` use it.
- **Pip sizing** uses the spec's `tickValue` / `tickSize`; `calculatePositionSize` rounds to the volume step.
